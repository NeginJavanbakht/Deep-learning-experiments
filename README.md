# 🧠 Machine Learning and Deep Learning Projects

Welcome to my collection of deep learning projects. This repository includes a variety of practical implementations using neural networks, CNNs, LSTMs, and other techniques to solve business, computer vision, and time-series problems.

---

## 📁 Project List

### 1. 📉 Stock Market Prediction using a Deep LSTM
- **Description**: Uses a deep LSTM network to predict future stock prices based on historical data.
- **Dataset**: `all_stocks_5yr.xlsx`
- **Technologies**: LSTM, TensorFlow, MinMaxScaler

---

### 2. 🧾 ANN for a Business Problem (Telco Churn)
- **Description**: Artificial Neural Network built to predict customer churn for a telecommunications company.
- **Dataset**: `Telco-Customer-Churn.xlsx`
- **Problem**: Classification (Churn vs. Not Churn)
- **Technologies**: ANN, Keras, Scikit-learn

---

### 3. 👕 CNN Classifier for Fashion MNIST
- **Description**: Convolutional Neural Network to classify images from the Fashion MNIST dataset (e.g., shoes, shirts, bags).
- **Model**: Simple 2D CNN with dropout
- **Dataset**: Fashion MNIST (via `tensorflow.keras.datasets`)

---

### 4. ✍️ CNN Classifier for MNIST Handwritten Digits
- **Description**: Image classification model for recognizing handwritten digits (0–9).
- **Model**: CNN
- **Dataset**: MNIST (via `tensorflow.keras.datasets`)

---

### 5. 🔍 Defect Detection with CNN
- **Description**: Lightweight CNN-based binary classifier to detect manufacturing defects (dataset assumed/preprocessed).
- **Use Case**: Industrial quality assurance
- **Technologies**: Keras, OpenCV
